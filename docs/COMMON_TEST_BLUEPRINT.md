# 共テ形式・到達判定ブループリント

## 目的

概念練習の正答率と、共通テスト本番での得点は別物です。この文書では、外部教材なしで6割を目指すために、アプリ内で説明、練習、本番想定、振り返りを完結させるための要件を定めます。

試験時間、構成、配点などの数値は、実装時に最新の公式仕様を確認して設定します。この文書は特定年度の公式問題や過去問の転載ではなく、必要な機能と検証方法の設計です。

## 三つのモード

### 概念モード

目的は「知らない概念を説明から一問目まで進める」ことです。短い説明、最小例、確認問題、誤答原因、再テストを扱います。

### 分野練習モード

目的は「同じ概念を表現違いで使える」ことです。quick、standard、transferを分け、正答だけでなく途中の考え方を振り返ります。

### 本番想定モード

目的は「長い文章・資料・誘導を読み、時間と配点の制約で得点する」ことです。概念モードの正答率を本番得点として表示しません。

## 本番想定モードの必須要件

- 最新の公式仕様に基づく試験時間と構成。
- 複数の設問を一つの文脈でつなぐ大問。
- 前の設問の結果を後の設問で使う誘導。
- 文章、表、グラフ、図などの資料。
- 必要情報と不要情報を区別する設問。
- 設問別の配点と、未回答・部分点の扱い。
- 実時間のカウント、途中保存、時間切れ、見直し。
- 科目別、設問タイプ別、誤答原因別の結果。
- すべてオリジナルの文章・数値・図。過去問の長文転載はしない。

## データモデル案

本番用の問題は、単問のProblemだけでなく次の階層を持ちます。

| 階層 | 主な情報 |
| --- | --- |
| Mock | 試験時間、構成、公開日、採点方式 |
| Section | 科目、順番、セクション時間、合計配点 |
| BigQuestion | 文脈、資料、誘導、設問のまとまり |
| Item | 選択肢、入力形式、正答、配点、部分点、関連概念 |
| Review | 誤答原因、解説、再テスト問題、次回日時 |

## 採点の分離

表示を次の三つに分けます。

1. 練習正答率：概念・問題レイヤーごとの学習指標。
2. 模試得点：本番想定モードの配点に基づく得点。
3. 到達判定：異なる模試を複数回受けた結果から、事前に定めた基準を満たしたか。

8問のスキル確認は診断用として残してよいですが、模試得点や6割判定には混ぜません。

## 6割判定の条件

次の条件を画面とログに残します。

- 使用した模試IDが互いに異なる。
- 問題はアプリ内のオリジナル問題だけである。
- 外部教材を使わない期間と、模試の受験条件を記録する。
- 本番想定時間内に提出している。
- 同じ模試の解説を見た後に再受験していない。
- 3回分の得点、時間、未回答、誤答原因を保存する。
- 3回の結果が事前に決めた6割基準を満たす。

この条件を満たしても、すべての利用者に将来の本番得点を保証するものではありません。「アプリ単体での到達を確認できる」という、限定したプロダクト判定です。

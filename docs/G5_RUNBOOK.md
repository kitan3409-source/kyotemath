# G5実測ランブック

G5は、アプリが完成したという自己評価ではなく、実ユーザーが未見フォームで得た結果を記録するゲートです。結果が揃うまで、READMEや画面で「6割達成」「到達保証」と断定しません。

## 対象

- 数学I・数学A：未見フォーム3つ（IA-F1〜IA-F3）
- 数学II・数学B・数学C：未見フォーム3つ（IIBC-F1〜IIBC-F3）
- Math IIIは教材トラックとして利用できるが、共テ6割の分母には入れない。

## 実施条件

1. 学習者は外部教材・過去問解説を使わず、このアプリ内の説明・問題・復習だけで準備する。
2. 各フォームは指定時間内に開始・提出する。IA/IIBCは70分、Math IIIは100分。
3. 提出前に解説や正答を見ない。
4. フォームごとに、フォームID、開始時刻、提出時刻、得点、未回答、時間切れ、設問別結果を保存する。
5. IAの3回すべて、IIBCの3回すべてが60/100点以上であることを確認する。

## 判定

- 6行すべてが条件を満たす：G5 PASS。
- 1行でも60点未満、時間超過、提出前の解説閲覧、記録欠落がある：G5未達または再実施。
- 1回の高得点やアプリ内の習得率だけではG5 PASSにしない。

この記録を作成したら、`docs/GOAL_SUCCESS.md` と `docs/INDEPENDENT_AUDIT_REPORT.md` のG5欄を、実際のフォーム記録と一緒に更新する。

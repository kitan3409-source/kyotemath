## 科目構成の要点

- **地歴公民・理科の2科目受験**: 「第1解答科目」（前半60分）+「第2解答科目」（後半60分）。大学が「第1解答科目の成績を利用」と指定する場合がある（鳥取大・香川大が該当）。**「公共，政治・経済」を第1解答科目にするのが安全**。
- **地歴公民の科目名**: 「地理総合，地理探究」「歴史総合，日本史探究」「歴史総合，世界史探究」「地理総合／歴史総合／公共」（3範囲中2範囲選択）「公共，倫理」「公共，政治・経済」。**「公共，倫理」と「公共，政治・経済」の組み合わせは不可**。
- **理科の科目名**: 「物理基礎／化学基礎／生物基礎／地学基礎」（4範囲中2範囲選択）、「物理」「化学」「生物」「地学」。
- **数学②**: 数学Ⅱは必須解答、数学B・Cは「数列」「統計的な推測」「ベクトル」「平面上の曲線と複素数平面」の4領域から3領域を選択解答。
- **国語**: 200点満点、分野別成績（近代以降の文章／古典）も提供。古典は古文+漢文で約100点分。
- **英語**: リーディング100点 + リスニング100点。大学側での換算例: R×1.6 + L×0.4 = 200点換算（広島市立大・香川大・鳥取大すべて同じ換算式）。リスニング欠席は0点扱いの大学が多い（鳥取大は明示）。
- **情報Ⅰ**: 100点。情報社会の課題/データの活用/情報システム/ネットワーク・セキュリティ/情報デザイン/疑似言語によるアルゴリズム/統計・データ読解 が範囲。疑似コードは大学入試センター定義の疑似言語表記。

## 満点構成（受験登録済みの9科目）

国語200 + 数学①100 + 数学②100 + 英語R100 + 英語L100 + 理科2科目200 + 地歴公民2科目200 + 情報Ⅰ100 = **1000点満点**。

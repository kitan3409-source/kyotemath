# 次回アップデート計画

> 2026-08-18時点で、教材・学習ループ・模試エンジン・保存境界の実装は現行リリースで独立監査の実装ゲートを通過しました。現行データの共テ幹線は `priority=core` の239概念です。残る実測タスクはG5（実ユーザーによる未見フォーム各3回）と、ブラウザ実体でのE2E確認です。以下の旧計画表は履歴として残し、現行の判定は [INDEPENDENT_AUDIT_REPORT.md](INDEPENDENT_AUDIT_REPORT.md) に集約します。

旧計画表の「225」は、概念分割を確定する前の目標値です。現在のデータ定義と画面上の幹線分母は239に統一しています。

## 目的

「問題を増やす」だけでは、外部教材なしで6割に到達できる保証になりません。次回は、説明の穴、本番形式、誤答からの復帰、実測の四つを順番に埋めます。

優先度は P0 が到達性を阻む必須項目、P1 が継続と精度を上げる項目、P2 が品質を安定させる項目です。

## リリースゲート

| ゲート | 合格条件 |
| --- | --- |
| G0 データ | 共テ225概念すべてに、説明・確認・標準・転用・誤答解説が紐づく |
| G1 レッスン | 225概念すべてで、外部教材なしに最初の一問まで到達できる |
| G2 模試 | 最新の公式仕様を確認した本番想定時間、構成、配点で、オリジナルのフル形式模試を複数作成できる |
| G3 学習ループ | 誤答原因を一タップで保存し、原因別の説明・類題・翌日再テストへ戻れる |
| G4 再開 | 中断、ブラウザ再起動、別日再訪問の後も、次の一手が一つに決まる |
| G5 到達判定 | 外部教材なしで、異なるオリジナル模試を3回受け、事前に決めた6割基準を安定して超える |

G5を満たすまでは、広告や画面上で「6割に到達できる」と断定しません。G5は個人の学習成果を保証するものではなく、このアプリの到達判定を曖昧にしないためのプロダクト基準です。

## P0：到達性を作る

### P0-01　完全レッスンを225概念へ拡張

現在の完全レッスンは100件で、追加対象は125件です。数学Iは完了しているため、まず不足の大きい順に埋めます。

| 科目 | 現在 | 目標 | 追加 |
| --- | ---: | ---: | ---: |
| 数学I | 52 | 52 | 0 |
| 数学A | 28 | 39 | 11 |
| 数学II | 17 | 62 | 45 |
| 数学B | 2 | 32 | 30 |
| 数学C | 1 | 40 | 39 |
| 合計 | 100 | 225 | 125 |

各レッスンの最低構成は、目的、直感または意味、定義・条件、最小例、典型手順、よくある誤り、確認問題、別表現の転用問題、共テでの見分け方です。説明を追加しただけで完了にせず、解答根拠と誤答解説までレビューします。

### P0-02　本番想定のオリジナル模試エンジン

- 最新の公式仕様を確認し、試験時間、構成、配点、提出方法を設定ファイルに分離する。
- 単問の集合ではなく、大問、設問間の誘導、文章、表、グラフ、必要な資料を持てる型へ拡張する。
- 段階的な誘導に沿う問題と、情報を取捨選択する問題を含める。
- 実時間制限、途中保存、時間切れ、見直し、未回答を実装する。
- 配点と部分点の扱いをデータとして持ち、正答数ではなく得点で集計する。
- 過去問の文章や図を転載せず、形式だけを参考にしたオリジナル問題にする。

### P0-03　誤答タイプと再ルート

不正解または自信なしの後に、次の中から一つだけ選べるようにします。

| 誤答タイプ | 次に出すもの |
| --- | --- |
| 条件・文章の読み落とし | 条件のマーキング練習と短い再読問題 |
| 方針が立たない | 使う道具を選ぶ練習と最小例 |
| 手順の途中で停止 | 一手だけ埋める分解問題 |
| 計算・符号・転記 | 途中式チェックと同型の短問 |
| 時間切れ・焦り | 制限時間を小さくした優先順位練習 |
| たまたま正解・自信なし | 翌日の別表現再テスト |

選択は反省文を書かせず、1タップで完了させます。保存するのは原因、概念、問題、時刻、再テスト予定だけです。

## P1：継続しやすさと判定精度

### P1-01　習得状態を分離

「説明を見た」「一問に着手した」「確認問題に正答した」「標準問題に正答した」「転用問題に正答した」を別状態にします。ガイド閲覧だけでは、前提条件を習得済みにしません。

### P1-02　中断と再開

- レッスンの現在位置を保存する。
- 画面を閉じた後の再開カードを一つだけ表示する。
- 失敗した問題は、正答表示で終了扱いにせず、理解確認または再テストを残す。
- 今日のセッションに「続きから」「3分だけ」「終了」の三択だけを置く。
- 連続日数や未達を責める表示を作らない。

### P1-03　基準模試と診断

- 初回に短い診断を行い、概念別の開始地点を決める。
- 学習中の練習結果と、本番想定模試の結果を別グラフにする。
- 科目別、設問タイプ別、誤答原因別に、次の一手を一つだけ提案する。
- 模試は「練習」と「判定」を分け、練習の正答率を本番得点と混ぜない。

## P2：品質を落とさず量を増やす

- 225概念の全レイヤーを自動検査する。
- 正答が一つに決まるか、解説が答えと一致するかを検査する。
- 同じテンプレートの数字置換だけになっていないかをレビューする。
- 大問の誘導が後半の設問を実際に助けるかを人手確認する。
- モバイル表示、キーボード操作、色だけに依存しないフィードバックを確認する。
- 既存の test、lint、build に、模試採点と保存・復帰のテストを追加する。
